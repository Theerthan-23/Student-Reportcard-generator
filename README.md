# 📘 Student Report Card Generator (Python)

## 📌 Description
This is a simple Python program that generates a report card for multiple students.

The program:
- Stores student names and their marks using a dictionary
- Calculates total marks
- Calculates average marks
- Assigns grades based on the average
- Prints a neat report card for each student

This project was created while learning Python fundamentals.

---

## 🧠 Concepts Used
- Dictionaries
- Lists
- For loops
- Nested loops
- Conditional statements (if / elif / else)
- Basic arithmetic
- Formatted output

---

## 🧪 How the Program Works
1. Student names are stored as keys in a dictionary.
2. Each student has a list of marks as values.
3. The program loops through each student.
4. It calculates:
   - Total marks
   - Average marks
   - Grade (A / B / C)
5. A formatted report card is printed.
